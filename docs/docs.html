Documentation

Everything you can do inside PlexOS today: the shell, the apps, the shortcuts — and an honest look at daily usability.

Getting started

Boot the plexos.iso on QEMU and you land straight on the desktop. The Start menu (top-left icon, or F10) lists all six apps. The terminal — PlexTerm — opens a real shell where help shows the command overview.

No installation, no login: PlexOS boots to a working desktop in a couple of seconds. The system keeps files in a memory partition (/ram) plus any ATA disk you attach (/dev/hda).

Usability & honest expectations

This is a from-scratch hobby kernel, so a few things are consciously simple. Here is the score sheet, straight from the developers:

Boot to desktop (QEMU)9/10
Files & folders8/10
Text editing7/10
Calculator9/10
Networking3/10
Hardware compatibility2/10
⚠ Still in development Display on real hardware / forced 1080p: the kernel keeps running but shows a red "STILL IN DEVELOPMENT" notice when the display can't be initialized.
What works daily: boot in seconds, GUI with windows and Start menu, file management, calculator, editor, shell with history, themes, power off/reboot.
What is still young: networking is limited (e1000 link + test TX, no TCP/IP stack yet), no USB driver (PS/2 input only), no user management, browser is offline-only, and heavy sleep pauses the whole GUI because scheduling is cooperative.
Real hardware: on the Intel i3-1115G4 the kernel is alive but the display path is still being worked on — when it can't init, a red STILL IN DEVELOPMENT screen appears instead of silent black, and CAPS-LOCK blink codes 1-11 trace the boot.
